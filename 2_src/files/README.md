# NumPy+OpenCV CNN 画像分類システム
外部MLライブラリ不要・NumPy+OpenCVのみで実装したCNN（畳み込みニューラルネット）

---

## ファイル構成

```
train.py    ← 学習スクリプト
camera.py   ← カメラリアルタイム判別スクリプト
model.pkl   ← 学習後に生成されるモデルファイル
```

---

## ① 学習データの準備

クラスごとにフォルダを分けて画像を入れる（1クラスあたり20枚以上推奨）

```
images/
  cat/        ← クラス0の画像（例：猫）
    cat01.jpg
    cat02.jpg
    ...
  dog/        ← クラス1の画像（例：犬）
    dog01.jpg
    ...
```

---

## ② 学習

```bash
python train.py --class0 ./images/cat --class1 ./images/dog
```

### オプション
| オプション | デフォルト | 説明 |
|-----------|-----------|------|
| `--class0` | 必須 | クラス0の画像フォルダ |
| `--class1` | 必須 | クラス1の画像フォルダ |
| `--model`  | model.pkl | 保存先モデルパス |
| `--epochs` | 30 | 学習エポック数 |
| `--lr`     | 0.01 | 学習率 |
| `--batch`  | 16 | バッチサイズ |

---

## ③ カメラでリアルタイム判別

```bash
python camera.py --model model.pkl
```

- `src` ウィンドウ：生カメラ映像
- `dst` ウィンドウ：判定結果付き映像（クラス名 + 確信度バー）
- `q` キーで終了

---

## ネットワーク構造

```
入力 (1ch, 32×32)
 ↓
Conv1 (3×3, 8フィルタ) + ReLU
 ↓
MaxPool (2×2) → 16×16
 ↓
Conv2 (3×3, 16フィルタ) + ReLU
 ↓
MaxPool (2×2) → 8×8
 ↓
Flatten → 1024次元
 ↓
FC1 (64ノード) + ReLU
 ↓
FC2 (1ノード) + Sigmoid
 ↓
出力: 0〜1の確率 (≥0.5 → クラス1)
```

## ラズパイ5での実行時間の目安

| フェーズ | 目安 |
|---------|------|
| 学習（100枚×30エポック） | 5〜15分 |
| 推論1フレーム | 100〜300ms |
| カメラ表示（5フレームに1回推論） | 約5fps |
